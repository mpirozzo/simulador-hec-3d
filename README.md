# Simulador de trauma craneal 3D

Simulador interactivo -HIC, BrIC, golpe/contragolpe, LAD- sobre una cabeza humana 3D translucida.

Ver en vivo: https://mpirozzo.github.io/simulador-hec-3d/

Creditos: three.js MIT; modelo de cabeza LeePerrySmith de Infinite-Realities, licencia CC-BY 3.0; autor dr.pirozzo_neurocirujano.

Modelo cualitativo con fines didacticos. No apto para uso clinico.
